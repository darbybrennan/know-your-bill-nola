What I couldn't figure out

  • Ward(s). Algiers is officially the 15th Ward, but every Algiers row says 13. The codes don't match official ward numbers.
  • "Living Square Feet." Holds counts like 1, 2, 3 that equal Assessment Record Count, so it isn't square footage. The file has no real building size.
  • Freeze codes 2, 3, 4 and Value Other Exemption codes: meanings are my best guess from the data, not documented.
  • LTC Subclass Codes (3400, 4000, 4020…): need the Louisiana Tax Commission's code table.
  • Place FIPS codes (96007, 96009…): they move with the Ward field, and no meaning is given.
  • Special districts. There's no tax district number, so the Garden District, DDD, or security-district fees can't be added to the bill estimate.
  • Act 718 phase-in. Nothing marks parcels whose increase is being phased in.
  • Verified Sale Indicator is "N" in every row, so real sales can only be told apart by price.

Checks that hold in every row

Land market value + building market value = total market value (100% of rows)
Land assessed + building assessed = total assessed value (100% of rows)
Total assessed − all exemptions = taxable assessed value (100% of rows)
Traps: Year Built 1994 and Transfer Date 12/31/1994 are placeholders. Purchase prices of 0, 10, and 100 aren't sales. Taxpayer IDs are zeroed out for privacy. Owner names exist in the file but are never used by this tool.

Join key: Tax Bill # = Parcel ID(s). The official bill for any parcel is at taxbills.nola.gov/pdfs/2026/<Tax Bill #>.pdf.
