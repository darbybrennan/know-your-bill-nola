Behind the data

Sources and method

How the tool is built, the rules the chatbot follows, and every source it is allowed to use.

How it's built

1 · Address → parcelThe matcher runs in your browser and loads only the slice of the roll for that street's first letter. Your address never leaves the page.
2 · Bill estimateComputed by page code, not by AI, with the 2026 millage. Checked against 14 real bills.
3 · Question → ClaudeYour question plus the one property on screen go to a small server function that calls Claude with fixed rules and a 18-source knowledge base.
4 · Answer with sourcesClaude returns an answer, source tags, and a handoff. The page turns tags into links and labels anything unsourced "unverified."

Hosted on Vercel from GitHub. The API key lives only on the server. Rate-limited per visitor. Nothing typed is stored. Built with Claude Code; the project's instruction file (CLAUDE.md) is in the GitHub repo.

The chatbot's rules

  1. Cite a source for every fact. No source means the answer is labeled unverified.
  2. Say "I don't know" when the sources don't cover it, then name the right office. Never guess numbers, dates, or rules.
  3. No legal or tax advice. Explain how things work and what evidence counts; never say "you should appeal."
  4. Always offer a person. Every answer ends with the best office to call.
  5. Say it's a student prototype on every page. Never claim to be an official tool.
  6. Plain language. 8th-grade reading level, short answers, the math shown step by step.
  7. Be honest about time. Name the tax year, flag deadlines that passed, never call a pending vote decided.
  8. Orleans Parish only. Renters get a one-line redirect.
  9. Privacy. Public records only, no owner names, no guessing about an owner's situation.
  10. One property at a time. A new lookup starts a fresh chat.
